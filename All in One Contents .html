HTML

  • HTML stands for Hyper Text Markup Language. It is the standard markup language for documents designed to be displayed in a web browser. It can be assisted by technologies such as Cascading Style Sheets (CSS) and scripting languages such as JavaScript.

  • HTML describes the structure of a web page semantically and originally included cues for the appearance of the document. HTML elements are the building blocks of HTML pages. With HTML constructs, images and other objects such as interactive forms may be embedded into the rendered page.

  • HTML is a markup language, not a programming language. HTML elements are represented by tags, written using angle brackets. Tags such as head and body are used to mark up the start and end of an element.

  • HTML is a World Wide Web Consortium (W3C) Recommendation. The latest version, HTML5, was published in October 2014.

  • HTML is a core technology markup language of the Internet, alongside CSS and JavaScript.

  • HTML is a markup language that defines the structure and layout of a web page by using various tags and attributes.

  • HTML is used to create web pages and web applications, allowing developers to structure content, add multimedia elements, and create interactive features.

    Structure

  • HTML documents are structured with a series of elements, each defined by a tag. The basic structure of an HTML document includes the DOCTYPE declaration, html, head, and body tags.

  • The DOCTYPE declaration specifies the version of HTML being used, while the html tag is the root element that contains all other elements.

  • The head tag contains metadata about the document, such as the title, character set, and links to stylesheets or scripts.

  • The body tag contains the visible content of the web page, including text, images, links, and other elements.

  • HTML elements can be nested within each other to create complex structures, and attributes can be added to elements to provide additional information or functionality.

    Tags

  • HTML tags are used to define elements within an HTML document. Tags are enclosed in angle brackets and typically come in pairs, with an opening tag and a closing tag.

  • Common HTML tags include h1 to h6 for headings, p for paragraphs, a for links, img for images, and div for divisions or sections of content.

  • Some tags, such as img and br, are self-closing and do not require a separate closing tag.

  • Tags can also have attributes, which provide additional information about the element. For example, the href attribute in an a tag specifies the URL of the link, and the src attribute in an img tag specifies the source of the image.

  • HTML tags can be styled using CSS to control their appearance, such as font size, color, and layout.

    Attributes

  • HTML attributes provide additional information about an element and are specified within the opening tag of the element.

  • Attributes are written as name-value pairs, with the name followed by an equals sign and the value enclosed in quotes. For example, class="my-class" is an attribute that assigns a class to an element.

  • Common attributes include id for unique identification, class for styling with CSS, href for links, and src for images.

  • Attributes can also be used to control the behavior of elements, such as the target attribute in an a tag to specify where a link should open (e.g., in a new tab).

  • Some attributes are global and can be applied to any HTML element, such as style for inline CSS styles, title for tool tip text, and data-* attributes for custom data storage.

    Types of Path

  • In HTML, paths are used to specify the location of resources such as images, stylesheets, and scripts. There are two main types of paths: absolute paths and relative paths.

  • An absolute path provides the complete URL to a resource, including the protocol (e.g., http:// or https://), domain name, and file path. For example, https://example.com/images/photo.jpg is an absolute path.

  • A relative path specifies the location of a resource relative to the current document. It does not include the domain name or protocol. For example, if the current document is located at https://example.com/pages/page1.html, a relative path to an image in the same directory would be image.jpg, while a path to an image in a subdirectory would be images/photo.jpg.

  • Relative paths can also use special notations like ../ to move up one directory level. For example, if the current document is in a subdirectory, a relative path to an image in the parent directory would be ../image.jpg.

  • Using relative paths is often preferred for local development and when resources are hosted on the same server, as it allows for easier portability of the HTML document.

    Table

  • HTML tables are used to display data in a structured format, with rows and columns. Tables are created using the table tag, with each row defined by the tr tag and each cell defined by the td tag.

  • Tables can also include headers using the th tag, which is typically used for the first row of the table to provide column headings.

  • Attributes such as colspan and rowspan can be used to merge cells across multiple columns or rows, respectively.

  • Tables can be styled using CSS to control their appearance, such as borders, background colors, and font styles.

  • HTML tables are commonly used for displaying tabular data, such as financial reports, schedules, and product listings.

    Media

  • HTML supports various media types, including images, audio, and video, allowing developers to embed multimedia content into web pages.

  • Images can be added using the img tag, with the src attribute specifying the image source. For example, <img src="image.jpg" alt="Description">.

  • Audio can be embedded using the audio tag, with attributes such as controls to provide playback controls. For example, <audio src="audio.mp3" controls></audio>.

  • Video can be embedded using the video tag, with attributes such as controls, autoplay, and loop. For example, <video src="video.mp4" controls></video>.

    I Frames

  • IFrames (Inline Frames) allow developers to embed another HTML document within the current document. This is useful for displaying content from other sources, such as external websites or applications.

  • IFrames are created using the iframe tag, with the src attribute specifying the URL of the document to be embedded. For example, <iframe src="https://example.com"></iframe>.

  • IFrames can have attributes such as width and height to control their size, and frameborder to specify whether to display a border around the frame.

  • IFrames can also be styled using CSS to control their appearance, such as background color and border style.

  • Using IFrames can be useful for embedding content from other websites, but it is important to consider security implications, such as cross-origin restrictions and potential vulnerabilities.
